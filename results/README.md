# Result files

This directory contains raw CSV files used for the prototype measurements in the paper.

## prototype/

- `honest_idba_3host.csv`: honest requester workload against the IDBA verifier.
- `attacker_idba_3host.csv`: attacker requester workload against the IDBA verifier.
- `honest_keychallenge_3host.csv`: honest requester workload against the KeyChallenge-style baseline.
- `attacker_keychallenge_3host.csv`: attacker requester workload against the KeyChallenge-style baseline.

These CSVs were generated by `prototype/requester.py` and can be summarized with:

```bash
cd prototype
python3 summarize_results.py ../results/prototype/*.csv
```
